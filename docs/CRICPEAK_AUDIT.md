# Cricpeak audit

Source: `Sgoldiy/CRICSCORE` at commit `c4624a8` ("in app purchase"). Package `com.cricpeak.scorelive`, version 1.4.0 (code 4), minSdk 24, target/compile SDK 36. Single `app` module, Kotlin + Compose + Material 3, Retrofit/Gson, no Room, no DI, no real tests (only the template example tests). About 9,400 lines of Kotlin.

Nothing in the original repository was modified.

## 1. Screens and navigation

Single activity, portrait-locked, one `NavHost`. Routes:

| Route | Screen | What it does |
|---|---|---|
| `splash` | SplashScreen | Timed splash, then onboarding (first run) or home |
| `onboarding` | OnboardingScreen | 3 pages ("Welcome To Live", "World of Cricket", AI insights), native ads on pages 1 and 3 |
| `home` | CricScoreHomeScreen | Tabs LIVE / UPCOMING / COMPLETED; "Featured Matches" carousel; "Live Now" and "Upcoming Matches" sections; match cards with team logos, scores, overs; "AI Prediction" button on cards; top bar with menu and premium buttons; pull to refresh |
| `details/{matchId}` | MatchDetailsScreen | Tabs Summary / Scorecard / Commentary (below) |
| `prediction/{matchId}` | AIPredictionScreen | Gemini win probability, analysis text, 5 key players per side, "Content is generated by AI" notice, premium lock overlay |
| `player_profile` | PlayerProfileScreen | Photo, full name, CAPTAIN / WK badges, batting and bowling style, DOB, birthplace, height, biography |
| `menu` | MenuScreen | Rate Us, Share App, Notifications (system settings), Uninstall App, Privacy Policy |
| `purchase` | PurchaseScreen | Plans: 1 Month, 6 Month, 1 Year, Lifetime |
| `uninstall_feedback` | UninstallFeedbackScreen | Reason picker, "Keep using" / "Uninstall", feedback saved to Firebase |
| `privacy_policy` | PrivacyPolicyScreen | In-app policy text |

Dialogs: no-internet (blocking, with Retry), exit confirmation (with banner ad), reward policy consent, fantasy team result, "fantasy not available yet" info.

## 2. Cricpeak feature list

How each item was carried over, changed or dropped is in [ROADMAP.md](ROADMAP.md) and the README.

Match data
-  Live, upcoming and completed fixtures (30 of each)
-  Auto refresh every 5 seconds on home and on live match details
-  Featured carousel, live badge, competition name, venue, local start time
-  Background preload of scorecard and first commentary page for listed matches
-  Match header: both teams, innings scores, overs, result text, toss
-  Current batters (on-strike marker), current bowler, partnership, CRR and RRR
-  "Recent Balls" strip, last 5 overs, colour-coded (wicket, six, four, wide/no-ball, bye/leg-bye)
-  FOUR / SIX / WICKET animation when the score changes on refresh
-  Summary tab: squads for both teams (tap opens player profile), match info table (date, venue, toss; umpire fields exist but are always empty)
-  Scorecard tab: innings tabs (up to 4 for Tests), batting cards (R, B, 4s, 6s, SR, dismissal), extras breakdown, total, bowling cards (O, M, R, W, economy, dots, wides), fall of wickets is modelled
-  Commentary tab: innings switcher, ball-by-ball text, end-of-over summary cards (score, runs in over, wickets, run rate, batters, bowler), scroll pagination by `LastOverNumber`
-  Per-ball detail badges: line, length, shot type, fielding position, bat connection, footwork, dismissal type
-  Shot view (wagon-wheel style canvas for a single ball, from shot angle and magnitude)
-  Player profile from match squad data

AI
-  Gemini match prediction for upcoming matches (win %, analysis, key players)
-  "AI Fun Fantasy XI" from the 22 announced players (falls back to a random 11 if the AI fails)

Monetisation and growth
-  AdMob banners (15 placements), native ads, interstitials (30 s cooldown, on tab change), rewarded ads
-  Ad placements switched on and off remotely from Firebase Realtime Database `ads_config`
-  Rewarded-ad gating: live commentary unlocks 2 overs at a time; AI prediction unlocks 2 uses per ad
-  Premium via Play Billing: `monthly_sub`, `half_yearly_sub`, `yearly_sub`, `lifetime_access`; removes ads, unlocks AI fantasy, gold theme
-  iZooto push notifications (generic marketing push, not match-specific)
-  Install counter POST to `quanrix.com/devcount/upcount.php`
-  Rate, share, uninstall feedback

Not present in Cricpeak: series or tournament pages, points tables, team pages, rankings, news, search, favourites, match alerts, player comparison, Manhattan/worm graphs, widget, share scorecard, offline cache (memory only), light theme, tablet/landscape layout, tests.

## 3. APIs and services

### Cricket data: `https://apiv2.cricket.com.au/` (no key, no auth)

| Endpoint | Params | Used for |
|---|---|---|
| `GET mobile/views/fixtures` | `UpcomingFixturesCount`, `InProgressFixturesCount`, `CompletedFixturesCount` | Home lists |
| `GET mobile/views/scorecard` | `FixtureId`, `InningNumber?` | Match details and scorecard |
| `GET mobile/views/comments` | `FixtureId`, `InningNumber`, `LastOverNumber?` | Commentary, paged about 10 overs |
| `GET mobile/views/matches/{id}` | | Declared, never called |

The saved error response in `fixtures.json` mentions a `TeamIdFilterType` predicate, so the fixtures endpoint accepts at least a team filter that the app does not use.

Fields returned but unused or under-used by Cricpeak (these are what the new features can be built on):
- Over-by-over `TotalInningRuns`, `TotalInningWickets`, `RunsConceded`, `Runrate`: enough for Manhattan and worm graphs.
- Ball-level `ShotAngle`, `ShotMagnitude`, `LineTypeId`, `LengthTypeId`, `BattingShotTypeId`, `FieldingPosition`: enough for full-innings wagon wheels, pitch maps and per-batter scoring zones.
- `Wickets` (fall of wickets), `Partnership`, `Officials`, `Venue.Latitude/Longitude`, `TicketUrl`, `WinType`, `WinningMargin`, `Tour`, `Competition.BannerImageUrl`, `Competition.Formats`, `TeamColor`, `BackgroundImageUrl`.

What else the API offers was then probed directly; the results are in [API.md](API.md).

Important: this is Cricket Australia's own mobile-app backend. It is undocumented and the repository contains no licence or permission to use it.

### Other services
- Google Gemini (`gemini-1.5-flash` default, model and key overridable from Firebase `gemini_config`).
- Firebase Realtime Database (`ads_config`, `gemini_config`, uninstall feedback), Firebase Messaging and Analytics.
- AdMob, Google Play Billing 7, iZooto, `quanrix.com` install counter.

## 4. Problems found

Security
- A Gemini API key is hardcoded in `GeminiPredictionService.kt` and the repository is now public. It should be rotated.
- `google-services.json` (Firebase API key and database URL) and the iZooto app id are committed. A release APK is committed too.
- `usesCleartextTraffic="true"`; HTTP logging at BODY level in release builds.
- Premium status is a plain local boolean with no server verification.
- The manifest uses AdMob's sample application id, so the committed build is not the production configuration.

Correctness and quality
- 5-second polling runs for as long as the screen exists, including for completed matches on the home list, with no lifecycle awareness or backoff.
- Fantasy XI silently returns a random 11 when the AI fails, presented as an AI pick.
- Upcoming matches always trigger a Gemini call on open.
- Umpire and referee rows are hardcoded empty although `Officials` is in the response.
- `fixtures.json` and `temp.json` are saved error responses, not data.
- Network errors on scorecard are swallowed into an empty scorecard.
- No offline cache, no tests, one 2,600-line screen file, API classes inside the `ui` package.
